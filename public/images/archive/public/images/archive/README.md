# Historical photo archive

The text-only release does not publish images from the former Google Sites website.

When approved local image files are available, place them in category folders such as:

- `home/`
- `research/`
- `awards/`
- `talks/`
- `graduation/`
- `team/`
- `publications/`
- `contact/`

Use short lowercase filenames with hyphens, for example `team-spring-gathering-2021-01.jpg`. Keep the original files separately and confirm permission before public release.
